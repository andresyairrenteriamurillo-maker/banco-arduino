# Banco Arduino

Simulador de Arduino Uno con protoboard, revisión de circuitos y vista 3D, para la sala de sistemas.

- `Banco-Arduino.html`: el simulador. **Este es el archivo que se descarga en los PC** cuando abren el programa con internet.
- `index.html`: copia del mismo archivo, para abrirlo como página web con GitHub Pages (opcional).

## Publicar una versión nueva
1. Entra a este repositorio en github.com.
2. **Add file → Upload files**, arrastra el nuevo `Banco-Arduino.html` (y si quieres también `index.html`).
3. Escribe una nota corta (por ejemplo «versión con bloques») y pulsa **Commit changes**.

En unos minutos, cada PC que abra Banco Arduino con internet se actualiza solo.
